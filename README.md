# TSI-NLP-Project
Related Townsquare Interactive Projects

----------------------------------------------------------------
The usage of ParseUnstructuredData.py and compare_transcripts.py 
in this repository extend exclusively to the transcrips provided 
alled transcript1.txt and Transcript2.txt.

ParseUnstructuredData.py is an NLP script that reads an 
unstructured .txt transcript file and converts relevent info 
into a structured .json file to be used in a .csv report.
