# TSI-NLP-Project
Related Townsquare Interactive Projects

----------------------------------------------------------------
The primary purpose of this NLP is to read unstructured 
cancellation call transcripts into structured .json files so the 
methods and information within these calls can be used in larger 
scale analysis of retention metrics.

The usage of ParseUnstructuredData.py and compare_transcripts.py 
in this repository extend exclusively to the transcrips provided 
called transcript1.txt and Transcript2.txt.

ParseUnstructuredData.py is an NLP script that reads an 
unstructured .txt transcript file and converts relevent info 
into a structured .json file to be used in a .csv report.

compare_transcripts.py is a data analysis tool that loads two 
.txt transcript files and outputs various metrics and scores to 
compare the two transcripts.
